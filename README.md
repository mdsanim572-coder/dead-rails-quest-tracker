# Dead Rails Quest Tracker

A static, mobile-friendly checklist for Dead Rails challenges and personal goals.

## Features

- Current challenge checklist with categories and Bond rewards
- Separate Easter Egg section
- Retired/limited challenges separated from obtainable challenges
- Progress percentage and completion count
- Search and filters
- Custom checklist
- Emoji icons or locally uploaded image icons for custom tasks
- Local browser persistence via localStorage
- No backend or account required

## GitHub Pages

The repository includes a GitHub Actions workflow at `.github/workflows/pages.yml`.

If GitHub Pages is not already enabled for this repository, open:

**Settings → Pages → Source → GitHub Actions**

Then run the workflow (or push a new commit). The intended URL is:

https://mdsanim572-coder.github.io/dead-rails-quest-tracker/

## Data note

Dead Rails challenges can change with updates. Challenge data in the tracker was checked against community-maintained Dead Rails challenge documentation in October 2026. Limited/retired challenges are intentionally separated.
